# ניהול הזמנות בדים

אפליקציית ווב לניהול הזמנות: לקוחות, תשלומים, משלוחים ותזכורות — הכל במקום אחד.
נבנתה כקובץ HTML יחיד, בלי שרת ובלי התקנה.

## יכולות

- **ניהול הזמנות** — לקוח, טלפון, אימייל, כתובת, כמות ומחיר ליחידה
- **חישוב אוטומטי** — סכום מוצרים + דמי משלוח = סה״כ לתשלום
- **מעקב שלבים** — לא נשלח · נשלח ולא שולם · הושלם
- **תשלומים** — מזומן, העברה, ביט, צ׳ק (כולל תאריך פרעון ותזכורת הפקדה)
- **מספר הקצאה** — התראה אוטומטית כשהסה״כ עובר את הסף של רשות המסים
- **דוחות** — הכנסות, חוב פתוח, פילוח חודשי, לקוחות מובילים ואמצעי תשלום
- **תזכורות** — הוספת אירועים ל-Google Calendar בלחיצה
- **סנכרון** — Google Sheets דרך Apps Script
- **אקסל** — ייבוא וייצוא
- **PWA** — ניתן להתקנה כאפליקציה בטלפון ובמחשב, ועובד גם בלי אינטרנט
- **עיצוב** — עברית מלאה (RTL), מצב בהיר וכהה, מותאם לנייד

## חיבור לגיליון

כתובת הגיליון **אינה נמצאת בקוד** — היא נשמרת רק בדפדפן של המשתמש.
בפתיחה הראשונה בכל מכשיר נפתח חלון ההגדרות; יש להדביק בו את כתובת ה-Web App
של ה-Apps Script המחובר לגיליון (עם הרשאת גישה "כל אחד").

## מבנה

| קובץ | תפקיד |
|---|---|
| `index.html` | האפליקציה כולה — HTML, CSS ו-JavaScript |
| `sw.js` | Service Worker — מאפשר התקנה ועבודה בלי אינטרנט |

## הרצה מקומית

פתיחת `index.html` בדפדפן מספיקה לשימוש רגיל.
להתקנה כאפליקציה נדרשת הגשה דרך `https` (למשל GitHub Pages).
